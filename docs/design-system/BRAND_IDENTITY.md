# Brand Identity — AZZAM MARINE · Precision Marine Enterprise

**Status:** Mandatory  
**Logo asset:** `public/brand/azzam-marine-logo.png`  
**Art direction name:** **AZZAM MARINE — Precision Marine Enterprise**

## 1. Logo analysis (source of truth)

The official logo communicates:

| Signal | Expression in logo | UI translation |
|--------|--------------------|----------------|
| Depth / authority | Deep black–navy field, honeycomb mesh | Navy sidebar, structural chrome |
| Precision / energy | Electric / royal blue accents & glow | Primary actions, active nav, focus |
| Strength | Metallic silver shark + chrome ring | Cool neutrals, borders — **not** chrome UI |
| Urgency / brand punch | Red eye, stars, lower red field | Selective accent / danger only |
| Industry | Marine / mechanical shark motif | Product domain, not decorative sharks in UI |

### Logo rules (MUST)

| Rule | Detail |
|------|--------|
| MUST | Use `public/brand/azzam-marine-logo.png` |
| MUST | Preserve aspect ratio; do not crop essential content |
| MUST NOT | Redraw, recolor, distort, replace with ship icons, or use ROOTK |
| MUST NOT | Place the full detailed logo at tiny sizes where lettering fails |
| SHOULD | Circular container with breathing room on navy sidebar |
| SHOULD | Prefer logo in brand/header chrome — not beside every page title |
| Collapsed sidebar | Logo mark remains; text labels hide |

The logo may be bold and detailed. **The application MUST be more restrained** — translate identity into professional UI, do not copy 3D glow, bloom, or metallic lettering into components.

## 2. Art direction

**Feel:** Precision · Reliability · Industrial expertise · Operational clarity · Premium enterprise  

**MUST NOT resemble:** gaming UI, racing sites, sci-fi neon dashboards, generic admin templates, consumer landing pages, or literal metallic 3D interfaces.

### Workspace model (MUST)

| Region | Treatment |
|--------|-----------|
| Sidebar | Deep marine navy |
| Header | Refined white / near-white + subtle border |
| Page | Cool light background `#F4F7FC` |
| Content cards | White surfaces |
| Borders | Cool slate `#E2E8F0` |
| Active / primary | Controlled blue |
| Text | Dark readable ink |
| Red | Selective only |

Long working sessions and data clarity outrank decorative brand effects.

## 3. Color intent

- **Navy** — structure and brand recognition  
- **Blue** — interaction, selection, emphasis  
- **Red** — brand accent sparingly + destructive / negative semantics  
- **Silver** — expressed as cool neutrals and borders, **not** gradients that imitate chrome  

See [DESIGN_TOKENS.md](./DESIGN_TOKENS.md) for token names and values.

## 4. Voice & content

- Operational and concise  
- EN/AR parity  
- No marketing fluff on transactional screens  
- Follow [CONTENT_DISCIPLINE.md](./CONTENT_DISCIPLINE.md)

## 5. Where brand appears

| Surface | Brand expression |
|---------|------------------|
| Sidebar | Logo + navy + blue active |
| Header | Clean light chrome (no heavy logo repeat) |
| Dashboard / modules | Tokens, hierarchy, chart palette |
| Charts | [CHARTS_AND_DATA_VISUALIZATION.md](./CHARTS_AND_DATA_VISUALIZATION.md) |
