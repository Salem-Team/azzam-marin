## تعريف المشروع

يتمثل المشروع في تصميم وتطوير نظام إداري متكامل لإدارة شركة متخصصة في استيراد وتصدير وبيع قطع الغيار والمحركات البحرية.

يهدف النظام إلى توحيد وإدارة العمليات التشغيلية والإدارية والمالية الأساسية للشركة من خلال منصة مركزية واحدة، بما يشمل:

- إدارة المستخدمين والصلاحيات.
- إدارة الأصناف وقطع الغيار.
- إدارة المحركات البحرية.
- إدارة المخازن والمخزون.
- إدارة المشتريات والاستيراد.
- إدارة الموردين.
- إدارة العملاء.
- إدارة المبيعات.
- إدارة الصندوق والحسابات البنكية.
- إدارة أرصدة العملاء والموردين.
- إدارة المصروفات والتكاليف المرتبطة بالاستيراد.
- التقارير والإحصائيات.
- النسخ الاحتياطي واستعادة البيانات.
- التكامل مع الأجهزة الخارجية المتفق عليها.
- دعم اللغتين العربية والإنجليزية.

## المستخدمون والصلاحيات

يحتوي النظام على نظام متكامل لإدارة المستخدمين والأدوار والصلاحيات باستخدام Role-Based Access Control (RBAC).

### 2.1 مدير النظام

يتمكن من:

- إضافة المستخدمين.
- تعديل المستخدمين.
- تعطيل أو حذف المستخدمين وفق الصلاحيات.
- إنشاء وإدارة الأدوار.
- تحديد الصلاحيات.
- إدارة إعدادات النظام.
- الوصول إلى التقارير والإحصائيات.
- متابعة العمليات الرئيسية للنظام.

### 2.2 مدير المخازن

يتمكن من:

- إضافة الأصناف.
- تعديل بيانات الأصناف وفق الصلاحيات.
- استلام البضائع.
- إضافة المخزون.
- صرف المخزون.
- تحويل البضائع بين المخازن.
- إجراء الجرد.
- متابعة أرصدة المخزون.
- متابعة الأصناف الناقصة والراكدة.
- متابعة حركة المخزون.

### 2.3 قسم المبيعات

يتمكن من:

- إدارة العملاء.
- إنشاء عروض الأسعار.
- إصدار فواتير البيع.
- تسجيل مرتجعات المبيعات.
- متابعة عمليات البيع.
- متابعة أرصدة العملاء.
- البحث عن الأصناف والأسعار.

### 2.4 قسم الحسابات

يتمكن من:

- تسجيل المقبوضات.
- تسجيل المدفوعات.
- إدارة الصندوق.
- إدارة الحسابات البنكية.
- متابعة أرصدة العملاء.
- متابعة أرصدة الموردين.
- إصدار كشوف الحساب.
- متابعة أعمار الديون.
- استخراج التقارير المالية.

### 2.5 قسم المشتريات والاستيراد

يتمكن من:

- إنشاء أوامر الشراء.
- إدارة الموردين.
- تسجيل عمليات الاستيراد.
- متابعة الشحنات.
- تسجيل بيانات الحاويات.
- تسجيل تكاليف الشحن والتأمين والجمارك والمصروفات.
- توزيع تكاليف الاستيراد على الأصناف.
- متابعة حالة الشحنات.

## إدارة الأصناف وقطع الغيار

يوفر النظام وحدة متكاملة لإدارة الأصناف وقطع الغيار.

### 3.1 بيانات الصنف

تشمل:

- كود الصنف.
- اسم الصنف باللغة العربية.
- اسم الصنف باللغة الإنجليزية.
- الشركة المصنعة.
- بلد المنشأ.
- OEM Number.
- Part Number.
- نوع المحرك المرتبط.
- صورة الصنف.
- وحدة القياس.
- الحد الأدنى للمخزون.
- سعر التكلفة.
- سعر البيع.
- حالة الصنف.

### 3.2 البحث عن الأصناف

يدعم النظام البحث باستخدام:

- اسم الصنف.
- كود الصنف.
- Part Number.
- OEM Number.
- Serial Number.
- Barcode.

مع توفير آلية بحث مناسبة للتعامل مع حجم البيانات المستهدف.

## إدارة المحركات البحرية

يوفر النظام وحدة مستقلة لإدارة المحركات البحرية.

### بيانات المحرك

لكل محرك يتم تسجيل:

- الشركة المصنعة.
- الموديل.
- سنة الصنع.
- القدرة بالحصان.
- Serial Number.
- بلد المنشأ.
- البيانات الأساسية للمحرك.

### ربط المحرك بقطع الغيار

يتيح النظام ربط قطع الغيار بالمحركات، بما يسمح بمعرفة:

- قطع الغيار المتوافقة مع المحرك.
- القطع البديلة.
- القطع المرتبطة بموديل معين.
- سجل المبيعات المرتبطة بالمحرك عند توفر البيانات.

- دعم أكثر من 100,000 صنف.

## التدريب والدعم الفني

يشمل المشروع:

- تدريب الموظفين الأساسيين.
- شرح العمليات الرئيسية.
- شرح المستخدمين والصلاحيات.
- شرح إدارة المخزون.
- شرح المبيعات والمشتريات.
- شرح الحسابات والتقارير.
- تدريب تشغيلي على النظام.

كما يشمل المشروع دعمًا فنيًا لمدة 12 شهرًا بعد Go-Live.

ويشمل الدعم الفني معالجة الأخطاء البرمجية والمشكلات المتعلقة بالوظائف المتفق عليها.

ولا يشمل الدعم الفني:

- إضافة Modules جديدة.
- تطوير خصائص جديدة.
- تغيير جوهري في نطاق النظام.
- تكاملات جديدة.
- تطويرات خاصة لم يتم الاتفاق عليها.

وتعامل هذه الطلبات باعتبارها Change Requests ويتم تقييمها والاتفاق عليها بشكل مستقل.

## مراحل التنفيذ والمدة الزمنية

مدة تنفيذ المشروع:

**45 يوم عمل فعلي**

- أيام الجمعة والسبت.
- العطلات الرسمية.
- الإجازات الرسمية المعتمدة.

يعتبر النظام جاهزًا للاستلام النهائي عند تحقق الوظائف الأساسية المتفق عليها، ومنها:

## 27. التسعير متعدد العملات وإدارة سعر الصرف

نظرًا لطبيعة نشاط الشركة واعتماد جزء كبير من عمليات الشراء والاستيراد والتسعير على الدولار الأمريكي، يدعم النظام إدارة وتسعير الأصناف باستخدام أكثر من عملة، وعلى رأسها USD وEGP.

### بيانات التسعير لكل صنف

يتيح النظام تسجيل وإدارة:

- تكلفة الشراء بالدولار الأمريكي.
- تكلفة الشراء بالعملة المحلية عند الحاجة.
- سعر البيع بالدولار الأمريكي.
- نسبة الربح المستهدفة.
- سعر البيع بالجنيه المصري.
- سعر الصرف المستخدم في احتساب السعر.
- تاريخ آخر تحديث للسعر.
- مصدر أو نوع سعر الصرف المعتمد داخل النظام.

### احتساب سعر البيع

يمكن للنظام احتساب سعر البيع بالجنيه المصري تلقائيًا بناءً على:

**سعر البيع بالدولار × سعر الصرف المعتمد = سعر البيع بالجنيه المصري**

كما يمكن احتساب سعر البيع بناءً على نسبة ربح محددة وفق إعدادات الصنف أو الفئة.

ويتم الاحتفاظ بسعر الصرف الذي تم استخدامه عند آخر عملية تسعير، بما يسمح بتتبع سبب وتاريخ أي تغيير في السعر.

ويكون سعر الصرف المعتمد داخل النظام هو الأساس المستخدم في عمليات التسعير التلقائي وفق إعدادات الشركة.

## 29. إعادة التسعير التلقائي

عند تحديث سعر الصرف، يتيح النظام إعادة تسعير الأصناف تلقائيًا وفق الإعدادات المعتمدة.

وتشمل آلية إعادة التسعير:

- إعادة حساب أسعار البيع بالجنيه المصري.
- الحفاظ على سعر البيع بالدولار عند الحاجة.
- الحفاظ على نسبة الربح المحددة للصنف.
- تحديث الأسعار وفق سعر الصرف الجديد.
- إمكانية اختيار الأصناف التي سيتم إعادة تسعيرها.
- إمكانية معاينة التغييرات قبل اعتمادها.

ولا يتم اعتماد التغييرات الجماعية على الأسعار إلا بعد تأكيد المستخدم المخول بذلك.

- عرض قيمة التكلفة قبل التوزيع.
- عرض التكلفة التي سيتم تحميلها على كل صنف.
- مراجعة التوزيع قبل الاعتماد.
- اعتماد التوزيع.
- تحديث التكلفة النهائية للأصناف.
- الاحتفاظ بسجل عملية التوزيع.
