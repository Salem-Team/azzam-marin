# AZZAM MARINE ERP

Enterprise frontend for AZZAM MARINE — marine engines, spare parts, inventory,
purchasing, sales, pricing, and finance.

**Stack:** Next.js 16 · TypeScript · Tailwind CSS 4 · Lucide · App Router

## Design system (mandatory)

All UI work MUST follow the official design system:

→ **[docs/design-system/README.md](docs/design-system/README.md)**

Tokens: `src/styles/tokens.css` · Utilities: `src/styles/utilities.css`

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
npm run typecheck
```

## Scope notes

- Application shell + bilingual navigation (8 groups / 42 entries) are implemented.
- Module pages are frontend placeholders ready for backend integration.
- No backend, database, or API layer is included in this repository stage.
